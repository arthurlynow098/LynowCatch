# LynowCatch — comece aqui

Execute INICIAR.bat no Windows e abra http://localhost:8765.
Requer Python 3.10+ e FFmpeg com ffprobe. Instalação de mídia: `winget install --id Gyan.FFmpeg --exact`.

A documentação completa está em README.md. Consulte docs/GUIA.md para instruções, docs/API.md para a API local e docs/ARQUITETURA.md para decisões técnicas e limitações.

Os resultados ficam em web/files. A fila é temporária; o histórico é guardado no navegador. Use somente conteúdo autorizado. Mantenha o motor restrito ao computador local.
